# De-identified Clinical Simulation Console

This public prototype uses fictional, de-identified patient labels and generated waveforms. It does not include raw waveform exports or real patient information.

## Run

1. Open a terminal in this folder.
2. Install dependencies: `python3 -m pip install -r requirements.txt`
3. Start the app: `python3 app.py`
4. Open `http://localhost:5000`

The app works immediately with generated waveforms. Raw clinical exports and trained model artifacts are intentionally excluded from this public repository.
